# 소각 집계 브라우저 검증

2026-11-19, 로컬 감바쓰 웹과 API에 새 Chrome 프로필로 접속해 확인했다.

| 동작 | 확인한 결과 |
| --- | --- |
| 새 브라우저로 홈 방문 | 사이드바에 소각 0개가 표시됐다. |
| 내 메시지 2개와 감자 답장 1개를 길게 누름 | 바구니에 3개가 표시됐다. 선택하지 않은 메시지도 대화에 남아 있었다. |
| 소각을 시작하고 첫 삭제 요청의 연결을 차단 | 완료 화면으로 이동하지 않았다. 다시 시도 버튼이 나타났고, API에서 원래 대화를 읽을 수 있었다. 세션 키와 누적 0개도 유지됐다. |

| 완료 화면 새로고침과 홈 재방문 | 누적 3개를 유지했다. |
