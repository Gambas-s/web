# Requirements

## Goal

감바쓰의 소각 개수를 실제 소각 결과에 맞게 집계하고, 전체 사용자 화면에서 표시만 되거나 제대로 동작하지 않는 기능을 점검한다.

## In Scope

- 소각 개수는 저장값이 없는 현재 브라우저에서 0부터 시작한다.
- 소각 개수는 같은 브라우저에서 재방문해도 유지한다.
- 사이트 데이터를 삭제하면 소각 개수를 0으로 초기화한다.
- 작성자와 관계없이 사용자가 직접 구긴 메시지 하나를 1개로 센다.
- 직접 구긴 메시지를 모두 소각하고 대화 삭제까지 성공한 뒤 해당 개수를 한 번만 합산한다.
- 소각 진행 중이거나 소각 또는 대화 삭제가 실패하면 개수를 증가시키지 않는다.
- 실패하면 기존 대화와 소각 개수를 유지하고 다시 시도할 수 있게 한다.
- 전체 사용자 화면에서 표시만 존재하거나 실제로 동작하지 않는 기능을 점검한다.
- 발견된 미완성 기능마다 위치, 현재 동작, 기대 동작, 검증 조건을 정리한다.

## Out of Scope

- 여러 브라우저나 기기 사이의 소각 개수 동기화
- 전체 사용자 누적 소각 통계
- 로그인 기반 사용자별 소각 통계
- 직접 구기지 않은 메시지의 소각 개수 집계

## Acceptance Conditions

- 저장값이 없는 브라우저에서는 소각 개수가 0으로 표시된다.
- 사용자 메시지 2개와 감자 답장 1개를 직접 구긴 뒤 모두 소각하고 대화 삭제가 성공하면 소각 개수가 정확히 3 증가한다.
- 사용자와 감자의 메시지는 작성자 구분 없이 하나당 1개로 집계된다.
- 직접 구긴 메시지가 모두 소각되기 전에는 소각 개수가 증가하지 않는다.
- 소각 또는 대화 삭제가 실패하면 소각 개수는 변하지 않는다.
- 실패하면 기존 대화가 유지되고 사용자가 다시 시도할 수 있다.
- 동일한 소각 완료 결과가 반복 처리되어도 소각 개수는 추가로 증가하지 않는다.
- 새로고침하거나 같은 브라우저로 재방문해도 소각 개수가 유지된다.
- 사이트 데이터를 삭제하면 소각 개수가 0으로 초기화된다.
- 전체 화면 점검 결과에는 각 미완성 기능의 위치, 현재 동작, 기대 동작, 검증 조건이 포함된다.

## Cautions

- 소각 개수는 현재 브라우저에만 유지되므로 다른 브라우저나 기기에는 공유되지 않는다.
- 사이트 데이터를 삭제하면 기존 소각 개수를 복구할 수 없다.
- 일부 메시지만 소각되거나 대화 삭제가 실패한 경우에는 개수를 합산하면 안 된다.
- 같은 소각 완료 결과가 반복 처리되어도 중복 합산하면 안 된다.
