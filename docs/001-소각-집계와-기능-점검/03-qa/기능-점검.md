# 감바쓰 전체 사용자 화면 기능 점검

최초 점검일은 2026-11-19이다. 이 문서는 당시 실제 브라우저에서 발견한 동작을 보존하고, 소각 집계 수정 뒤 다시 확인한 결과를 구분해 기록한다. 후속 후보는 이번 작업에서 구현하지 않는다.

## 화면별 점검 범위

| 화면 | 모바일 점검 범위 | 데스크톱 점검 범위 |
| --- | --- | --- |

## 소각 집계 수정 후 재확인

2026-11-19에 새 Chrome 프로필로 소각 집계와 삭제 실패 흐름을 다시 확인했다. 최초 점검의 사실을 덮어쓰지 않고 별도 결과로 남긴다.

- 새 브라우저의 홈에서 소각 수가 0개로 표시됐다.
- 내 메시지 2개와 감자 답장 1개를 직접 구겼을 때 바구니는 3개였고, 선택하지 않은 메시지는 대화에 남았다.
- 첫 삭제 요청 연결을 차단했을 때 완료 화면으로 이동하지 않았고 재시도 버튼이 나타났다. 서버의 원래 대화, 브라우저 세션 키와 누적 0개가 유지됐다.
- 재시도 중 서버의 삭제 성공 응답만 유실시킨 뒤 한 번 더 재시도했다. 세 요청은 같은 소각 식별자를 사용했고 완료 화면과 홈 사이드바에는 정확히 3개가 표시됐다.
- 완료 화면 새로고침과 홈 재방문 뒤 3개가 유지됐고, 로컬 저장소를 지운 뒤에는 0개로 돌아갔다.

## 점검 환경과 제한

- 데스크톱 Chrome과 모바일 크기 Chrome으로 홈, 채팅, 소각 진행, 소각 완료와 소각 기록을 확인했다. 모바일 점검 해상도는 390 × 844이며 실제 휴대전화에서 실행한 결과는 아니다.
- 기본 웹 주소는 점검 시작 시 웹 패키지 설정을 읽는 과정에서 HTTP 500을 반환했다. 같은 작업 트리의 화면 코드를 임시 폴더에서 실행해 기존 로컬 API와 Redis에 연결했다. 이후 기본 주소가 다시 200을 반환해 채팅 전송, 말풍선 3개 삭제 성공 응답과 모바일 삭제 실패 문제를 기본 주소에서도 재확인했다.
- 새 테스트 세션에서 메시지 전송, 감자 답장 수신, 대화 복원, 두 작성자의 말풍선 구기기, 소각 확인 취소, 정상 삭제와 완료 뒤 홈 이동을 확인했다. 오류 시나리오는 해당 테스트 세션의 네트워크 요청만 차단하거나 빈 테스트 세션을 종료해 재현했다.
- 당시 로컬 Node.js 26.6.0에서는 기본 웹 테스트에 브라우저 저장소가 제공되지 않아 42개 중 26개가 실패했다. 테스트 전용 저장소를 지정해 같은 코드를 실행했을 때는 42개가 모두 통과했다. 제품 동작은 브라우저에서 별도로 확인했다.
- 소각 수와 삭제 실패 처리는 승인된 범위로 수정·재확인했다. 세션 복구, 구긴 선택 새로고침, 기록 내용, 연속 일수·평균, 자동 소각 시계, 새 쓰레기통과 프로필은 구현 승인이 없는 후속 후보이다.
